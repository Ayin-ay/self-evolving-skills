# 技能审计标准

## 严重级别定义

| 级别 | 标签 | 定义 | 处理要求 |
|------|------|------|----------|
| P0 | Blocker | 导致 Skill 无法使用 | 必须修复后方可继续使用 |
| P1 | Error | 功能受影响但可部分使用 | 建议尽快修复 |
| P2 | Warning | 质量或体验问题 | 可选修复 |
| P3 | Info | 可优化但不影响功能 | 记录但不强制修复 |

## 检查项详细标准

### 文件结构检查

| 检查项 | 检查方法 | 严重级别 | 通过标准 |
|--------|----------|----------|----------|
| SKILL.md 存在 | 检查文件是否存在 | Blocker | 文件存在 |
| YAML frontmatter 存在 | 检查文件是否以 `---` 开头 | Blocker | 文件头两个 `---` 之间包含 metadata |
| name 字段 | 解析 YAML，检查 name 键 | Blocker | 存在且非空字符串 |
| description 字段 | 解析 YAML，检查 description 键 | Error | 存在且非空字符串 |
| 触发规则章节 | 检查是否包含触发规则描述 | Error | 包含"触发"或"auto_trigger"相关内容 |
| 步骤说明章节 | 检查是否包含步骤说明 | Error | 包含"步骤"或"Step"相关标题 |

### 内容质量检查

| 检查项 | 检查方法 | 严重级别 | 通过标准 |
|--------|----------|----------|----------|
| 正文长度 | 统计正文行数 | Warning | >= 50 行 |
| 具体指令 | 检查是否有可执行的操作说明 | Error | 包含具体操作描述，而非仅理念 |
| 指令清晰度 | 检查是否有模糊表述 | Warning | 尽量减少"酌情"、"适当"等模糊词 |
| 示例存在性 | 检查是否包含示例 | Info | 关键步骤有示例说明 |
| 错误处理 | 检查是否包含错误处理说明 | Warning | 包含常见错误场景及处理方式 |

### 引用完整性检查

| 检查项 | 检查方法 | 严重级别 | 通过标准 |
|--------|----------|----------|----------|
| 文件引用 | 提取所有 `文件路径` 引用，检查是否存在 | Error | 所有引用路径存在 |
| 脚本引用 | 提取所有 `scripts/` 引用，检查文件是否存在 | Error | 所有引用的脚本文件存在 |
| 参考文件引用 | 提取所有 `references/` 引用，检查文件是否存在 | Error | 所有引用的参考文件存在 |
| 目录引用 | 提取所有目录引用，检查目录是否存在 | Warning | 所有引用的目录存在 |

### 格式检查

| 检查项 | 检查方法 | 严重级别 | 通过标准 |
|--------|----------|----------|----------|
| Markdown 语法 | 检查常见语法错误 | Warning | 无语法错误 |
| 列表缩进 | 检查列表缩进一致性 | Warning | 同一层级缩进一致 |
| 代码块标记 | 检查代码块是否闭合 | Error | 所有代码块正确闭合 |
| 标题层级 | 检查标题是否跳级 | Warning | 标题层级不跳级（如从 ## 直接到 ####） |
| 表格格式 | 检查表格对齐 | Warning | 表格列对齐正确 |

### 去重检查

| 检查项 | 检查方法 | 严重级别 | 通过标准 |
|--------|----------|----------|----------|
| 跨 Skill 重复 | 检查不同 Skill 内容的相似度 | Warning | 相似度 < 70% |
| 文件内重复 | 检查同一文件内段落重复 | Warning | 无连续重复段落 |

## 评分公式

每个 Skill 的总体健康评分 = 100 - Σ(问题权重)

| 级别 | 每个问题扣分 |
|------|-------------|
| Blocker | 30 分 |
| Error | 15 分 |
| Warning | 5 分 |
| Info | 1 分 |

评分等级：
- 90-100: 优秀 (Excellent)
- 70-89: 良好 (Good)
- 50-69: 需改进 (Needs Improvement)
- < 50: 不合格 (Poor)
